# Sorting algorithms benchmark

This paper compares 7 of the most well established sorting algorithms used by programmers.

The paper is available as `main.pdf`.

## File structure

The `data/` directory holds the benchmarking results.

The `src/` directory holds the C++ sorting algorithm implementations
I have written myself.

The `build.sh` script builds the C++ source code.

The `benchmark.py` scripts does the actual benchmark.
